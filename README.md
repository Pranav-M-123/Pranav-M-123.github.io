# Pranav Maturi — Engineering ePortfolio

A static, responsive portfolio for GitHub Pages. No build step or external JavaScript dependencies.

## Publish
1. Back up the existing repository files.
2. Upload `index.html`, `style.css`, `script.js`, and the entire `assets/` folder to the root of `Pranav-M-123.github.io` on the `main` branch.
3. In repository Settings → Pages, confirm deployment from `main` / root (or the existing Pages deployment workflow).
4. Visit https://pranav-m-123.github.io/ in a private browsing window after deployment.

## Accessibility
Includes semantic sections, alt text, keyboard focus indicators, mobile navigation, and reduced-motion support.
